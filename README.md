# 📋 Painel de Tarefas (Kanban Board)

Um painel de gerenciamento de tarefas em estilo Kanban, desenvolvido para fins de aprendizado e aprimoramento de habilidades em desenvolvimento web front-end. O foco principal do projeto é explorar a manipulação do DOM e a **API nativa de Drag and Drop do HTML5** para criar uma experiência de usuário fluida e interativa, sem a dependência de bibliotecas externas.

## 🚀 Objetivo do Projeto

Praticar e consolidar conceitos fundamentais do ecossistema web vanilla (HTML, CSS e JavaScript), construindo uma ferramenta funcional de organização pessoal ou de projetos.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do painel, colunas e cartões de tarefas, utilizando os atributos nativos de arrastabilidade (`draggable="true"`).
- **CSS3:** Estilização moderna (utilizando Flexbox/Grid), design responsivo e efeitos visuais para feedback de arraste (ex: destacar a coluna quando um card estiver sobre ela).
- **JavaScript (ES6+):** Lógica de negócios, manipulação dinâmica do DOM e implementação dos eventos da Drag and Drop API (`dragstart`, `dragover`, `dragleave`, `drop`, `dragend`).

## ✨ Funcionalidades Planejadas / Implementadas

- [ ] **Movimentação Drag and Drop:** Arrastar tarefas livremente entre as colunas (ex: _A Fazer_, _Em Andamento_, _Concluído_).
- [ ] **Criação de Tarefas:** Adicionar novos cartões com título e descrição dinamicamente.
- [ ] **Exclusão/Edição:** Opção para remover ou editar o conteúdo de uma tarefa.
- [ ] **Persistência de Dados (Bônus):** Salvamento do estado do painel no `LocalStorage` para que os dados não sumam ao atualizar a página.
